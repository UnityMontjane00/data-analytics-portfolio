# Data Analytics Portfolio

## Turning Data Into Business Insights

This repository brings together my data analytics projects across Microsoft Excel, SQL, Python, and Power BI.

The goal is not simply to demonstrate knowledge of different technologies, but to demonstrate an understanding of the data analytics process from working with raw business data to producing insights that can support decision-making.

My approach is:

**Prepare → Query → Analyse → Visualise → Communicate**
